## Add yourself

Made a contribution? Add a row in the same pull request — no permission needed, no threshold to meet. One accepted typo fix belongs here as much as a feature.

```markdown
| [<img src="https://github.com/YOURHANDLE.png" width="48" alt="">](https://github.com/YOURHANDLE) | **Your Name** ([@YOURHANDLE](https://github.com/YOURHANDLE)) | 📝 — a question set on <subject> |
```

Prefer not to be listed, or want a different name or no avatar? Say so in your pull request; we will do exactly that.

GitHub's own [contributor graph](https://github.com/SriSatyaLokesh/pariksha/graphs/contributors) counts commits only, which is why this file exists: most of the work that makes an exam platform trustworthy never shows up as a commit.
