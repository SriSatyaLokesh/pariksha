# packages/core

Pure TypeScript with no I/O: the 12 question types, grading for all five scoring modes (all-or-nothing, partial, negative, position, rubric), seeded set/pool selection and question/option shuffling, and cross-field import validation for question banks. Every scoring path is unit-tested with fixtures. Proctoring policies and integrity-flag rules are not implemented here — they belong to a later phase.

**Status:** Phase 1 (foundation and scoring) has shipped. See [the phase 1 plan](../../docs/superpowers/plans/2026-10-16-phase-1-foundation-and-scoring.md) and [PRD — Question types and scoring](../../docs/PRD.md#question-types-and-scoring).
