# 0001. Record architecture decisions

- **Status:** Accepted
- **Date:** 2026-10-16

## Context

Pariksha is an open-source project that many people will contribute to over time. Without a written record, the reasons behind design choices are lost and the same debates repeat.

## Decision

We record significant decisions as short Markdown files in `docs/adr/`, numbered in order, using the template in `0000-template.md`.

## Consequences

Contributors can see why things are the way they are. Changing a decision means writing a new ADR that supersedes the old one.
